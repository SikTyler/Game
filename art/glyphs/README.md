# Input glyphs

PNG prompts copied unmodified from rsubtil/controller_icons @ 4246544
(https://github.com/rsubtil/controller_icons), folders `key`, `mouse`,
`xboxseries` (renamed `xbox`), `ps5` and `steamdeck` only (diagram sheets left out).

The images are **Xelu's FREE Controllers & Keyboard PROMPTS** by Nicolae (XELU)
Berbece, https://thoseawesomeguys.com/prompts/ — **CC0 1.0** (public domain), as stated
in the upstream README; a few key/mouse extras were contributed under the same CC0
terms by @TacticalLaptopBag and @DataPlusProgram. No addon code is used; the
addon's MIT license is kept here as `LICENSE.controller_icons-MIT.txt` for
provenance. The plugin icon (Godot logo, CC-BY-4.0) is NOT included.
