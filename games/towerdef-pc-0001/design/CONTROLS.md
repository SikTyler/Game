# Corehold V2 — controls

Defaults from `Keybinds.gd` (every action is rebindable in Settings → Controls, two key/mouse slots and one pad slot per action). Buttons fire on press; tooltips appear on hover (delay in Settings).

## Hub (between runs)

| Action | Keyboard / mouse | Pad |
|---|---|---|
| Outpost (home) | O | — |
| Core | K | — |
| Forge | J | — |
| Research | L | — |
| Reforge | Y | — |
| Missions | M | — |
| Records (stats, history, achievements) | H | Back |
| Back / close overlay | Esc | B |
| Confirm | Enter | A |
| Outpost: pan / zoom | right or middle drag / wheel | — |
| Outpost: move the build cursor; 1-9 arm the palette | arrow keys | left stick |
| Outpost: rotate the building being placed | Z | right stick click |
| Fullscreen | F11 or Alt+Enter | — |
| Screenshot | F12 | — |

Requirement chips (Core level, locked research) are buttons: click one to jump to the building or research it names.

## In a run

| Action | Keyboard / mouse | Pad |
|---|---|---|
| Pause | Space | Start |
| Game speed down / up (unlocked by Game Speed research) | F / G | LT / RT |
| Take a draft card | click it (or drag a building onto the grid) | A on the focused card |
| Reroll / Banish the draft | T / N | — |
| Lock a draft card | the lock button on the card | — |
| Specials (abilities) | Q W E R (slots 1-4) | — |
| Core Enhancements: buy the open tree's tracks 1-5 | Shift+1 … Shift+5 | — |
| Buy x1 / x5 / MAX | the mode button above the tracks (hold Shift for bulk) | — |
| Rotate a directional weapon (while placing, or the selected one) | Z / mouse wheel while placing | right stick click |
| Merge (selected building into its same-tier twin) | drag one onto the other, or the Merge button | — |
| Sell / demolish | X or Delete | Y |
| Building info | right click | X |
| Manual aim | hold left mouse on open field ≥ 0.15 s (focus meter builds to +30% damage) | right stick aims |
| Toggle side panels | Tab / Shift+Tab | — |
| Play again (new run) | Ctrl+R | — |
| Move the cursor | arrow keys | left stick |

## QOL research switches
- **Auto-Buy** (run panel AUTO button): off / Attack / Defense / Economy / all trees; buys at each wave start, keeping 25% of the cash.
- **Auto-Salvage** (bottom of the Forge panel): off / Commons / up to Uncommon.
- **Auto-Restart** (results screen): starts the next run after 8 s.
- **Loadout Presets** (Core → Presets tab): SAVE / LOAD up to 3 loadouts.
